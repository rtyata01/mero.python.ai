# ScamShield AI

AI-powered scam detection and threat intelligence platform focused on:
- phishing detection
- scam reasoning
- semantic retrieval (RAG)
- explainable AI responses
- future scam knowledge graph

## MVP Features
- Analyze emails/messages/URLs
- Semantic scam retrieval
- AI risk scoring
- Explainable recommendations
- FastAPI backend
- Free/open-source friendly stack

## Free Tech Stack
- FastAPI
- PostgreSQL
- Qdrant (local Docker)
- Redis
- SentenceTransformers
- Ollama (optional local LLM)
- Docker Compose
